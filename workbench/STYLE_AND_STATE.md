本轮目标：以用户在《归乡疫期》会话中贴出的原稿为首要风格样本，以后续 Claude 实际写出的正文为合作样本，修正 v0.1 的叙述方式；依照共享事件记录组织续写。

状态：分析与新开篇草稿；等待用户确认文风。没有把新正文采纳为正式手稿，没有改动 PLM 或 LightRAG。

## 2. 上一版偏离在哪里

v0.1 主要采用第三人称、短句对白和快速显形的威胁。它很快从见面进入抓握、挣脱、关门，读者随即确认危险。关系则集中在几句简短的含蓄对白。

《归乡疫期》的主要张力有另一套推进方式：

1. 第一人称贴着身体写。寒气、口罩内的气息、消毒水、拥挤和衣服里的汗先进入叙述；读者在主角作出解释之前，先承受他的环境。
2. 较长的段落允许观察、回忆、猜测与自我否定在同一段里逐步累积。短句用于压力积累后的停顿，不把所有动作切成镜头。
3. 外界仍有充分理由维持日常：要回家、赶车、工作、吃饭。正常秩序暂时解释得通，主角却越来越难受。
4. 害怕会损害主角的社会处境。他阻拦、打量、催促别人的行为，让旁人先觉得他不正常。危险还没有得到证明，他已经为自己的判断付出信誉与关系成本。
5. 通知、消息、岗位行为的变化，是世界变化抵达个人的通道。不能由后台旁白提前告诉读者发生了什么。
6. 实际事务承担人物塑造。谈租金时如何交换条件、采购时如何分配钱和运力、谁愿意相信谁，都可以推动情节。物品进入正文应改变选择，而不是只有名词清单。
7. 感情从具体交往中积累：一次等候、一句没敢说的话、看见对方害怕但仍在做事。不能只用冷静、聪明、漂亮几个标签替代关系过程。

这是一份针对当前文本的校准结果，不声称用户所有作品都具有相同文风。

## 3. 借用时仍要校正的部分

- 原稿第46行的“他们和我一样……知道真相”，属于叙述者对别人行为的解释。正文可以保留人物笃信时的力度；事件层不得因此认定所有工作人员掌握末日真相。
- 旧稿中的镭射眼发生在幻觉段，不能生成“主角已掌握镭射能力”的角色属性；也不将它带进当前版本。
- Claude 后期文本中的确定性金融、医学、地理解释，不能因为写得具体就当作现实核验结果。本轮只借实务推进叙事的方法。
- 不把反复出现的“指节泛白”“极度冷静”、每段结尾的宏大总结一律当作必需风格。感官细节应服务观察和行动，后续可以逐段减去重复。
- 不因人物一次能干就赋予稳定、万能的职业能力；表现出的能力与叙述者的赞叹分别登记。
- 读者获得与主角相同的证据，不意味着二者必须作出相同推断。题辞是用户明确保留的框架信息，但不提供幕后身份、年代或人物现场无法获得的答案。

## 4. 本轮试写选择

保留校园、等人、后楼梯和陌生来电，以便对照文风。改为第一人称，把上次的即时肢体袭击后移。开篇前半场依次经历：

日常等候 → 通知与环境的细小不适 → 有普通解释的门外人员 → 陌生人准确说出位置 → 阻拦出门产生尴尬 → 未来身份声明 → 通知改变通行要求。

本段不确认任何一个人已经转化，不让角色提前知道湿件或乐园，也不让读者看到2099年的后台。作者已定的外层现实继续保留。

保留的硬边界：南理工男学生；2026年生活环境；自称2029年的来电；AI引导方向；外层2099年乐园。移植旧稿的叙事方法，不移植北京上班族身份、春运路线、脑内常驻声音或已建成的南京安全屋。

## 5. 一个事件底账，四种派生视图

纠正 v0.1 的“四份记录”表述：维护一份共享事件底账。全局状态、因果关系、角色认知、叙事披露是对它的不同读取结果，不各写一套剧情。

数据见 [opening-v0.2.json](events/opening-v0.2.json)。

- 初始状态保存角色、地点、物品、组织、规则和持续过程。没有证据的身份与动机保留未知。
- 一个事件可以有多个前置条件、多名行动者及不同意图；动机边、条件边、信息边分开。
- 身体、持物、位置与权限变化由事件产生。正文未发生上楼，就不能在章节结束卡里把男主放进实验室。
- 时间至少分实际年代、场景年代、人物声明年代与正文披露位置；不得以记录创建时间代替故事时间。
- 每条判断分别保存来源身份、确定性与采纳状态。“用户明确设定”“模型候选”“角色自述”是不同来源；“新草稿里的明确事件”仍然不等于已经采纳的小说事实。
- 认知更新区分观察、得知某人这样说、相信、怀疑和隐瞒。两个出门者是否失踪目前未知，不能登记死亡。
- 持续过程在这一段里包括等候与通话，预防性清洁仅有通知声称和气味线索。感染扩张作为本版宏观机制保留，但本场没有足够材料计算谁已感染、何时转化。
- 因果图可标出删去警告将影响哪些行动依据，不能替代行为规则宣布主角必死。
- 本段只是开篇前半场；上楼救援尚未发生。派生角色卡与摘要必须停在真实写到的位置。

## 6. 下一场的写作入口

当前：男主仍在一楼后门内侧，通话未结束；女孩最后一次被看见走向楼上，确切房间未知；门已经合上，两个离楼者在视野之外；新通知要求暂留原处。

下一场先让男主联系眼前世界中的女孩。他需要分辨三项并不一致的信息：电话要求去找她、群通知要求留在原处、她本人对楼内情况的描述。她必须有自己的目标和信息来源。

男主可以选择上楼，但要写出他如何权衡、损失多少时间、为什么相信当前女孩的消息。这一场的完成标准是出现第一个由他作出的有代价的救援行动，而非靠旁白宣布他相信了未来。

若以后接回安全屋线，先建立有限的准备窗口。人数、现金、租金和押金、剩余采购额、车的容量、往返时间与营业变化必须互相约束；租金谈成要改变后续可行选择。具体数值在写到该场时再提案，暂不虚构已购库存。

## 7. 接续时给写作者的简明约束

以用户原稿为主要参考。第一人称，感官与物质环境先进入叙述；让日常解释维持一段时间。情报通过主角能接触的渠道进入。允许主角强烈误判，作者侧记录判断来源。人物在做事和互相牵制中显出性格。不要让所有段落都是短句对白，不提前用幕后真相制造刺激。

每次只交付一个明确边界的场景。检查正文、共享事件、角色当前位置与认知是否一致。风格是否已贴近用户，由用户对试稿的反馈确认。
